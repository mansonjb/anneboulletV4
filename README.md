# Anne Boullet Studio · V4 « La double page »

Quatrième direction : le site comme un livre ouvert. À gauche une image fixe, à droite le texte qui défile ;
chaque chapitre (et chaque projet, matière ou secteur survolé) tourne l'image par un volet.
Vélin, encre, rouge sang de bœuf ; Bodoni Moda + Instrument Sans. Même contenu, mêmes 32 pages, même SEO que les V1 à V3.

```bash
npm install
npm run dev
```
